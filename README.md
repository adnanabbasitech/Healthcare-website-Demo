# Raha Medical — Clinic & Laboratory Website

A bilingual (English/Arabic) React + Vite + Tailwind CSS starter website for a general clinic and diagnostic laboratory.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Included

- Responsive premium header
- Always-visible Book Appointment button on desktop and mobile
- English / Arabic language toggle with RTL support
- Home, About, Services, Laboratory, Doctors, Appointment, Contact and Health Journal pages
- Service detail routes
- Demo appointment form
- WhatsApp floating action
- Responsive footer

## Before production

Replace demo clinic details, doctor profiles, images, and educational copy with approved information. Connect the appointment form to a secure backend and approved communication workflow before accepting real patient data.
